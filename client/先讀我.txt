Anima 本機客戶端

目前狀態：程式完成，本機測試通過；遠端尚未開通，不能立即生成。

1. 安裝 Python 3.10+：https://www.python.org/downloads/
2. 安裝 GitHub CLI：https://cli.github.com/
3. Windows 雙擊 start-windows.bat；macOS/Linux 執行 bash start-mac-linux.sh。
4. 在自己裝置的瀏覽器登入 GitHub，勿在聊天貼 Token。
5. 遠端開通後，可送單、看資源快照，勾選自動下載取圖。
